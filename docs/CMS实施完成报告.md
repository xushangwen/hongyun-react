> 完成日期：2026-07-29

## 完成结论

本地完整链路已经落地并可运行：React 官网 → Nitro BFF → Strapi 5.51.0 → SQLite（生产配置支持 MySQL）。中文现有内容已幂等迁入，媒体已入库；前端新闻、产品分类、搜索和表单已接入 BFF。29 条产品展示路径（28 个唯一产品）及 7 个解决方案的详情接口已经就绪，但前端继续使用原有专用页面与受控布局，未再用通用 CMS 模板替换原视觉。

英文 `en` locale、接口参数和 404 语义已保留；当前英文已发布产品为 0，翻译和预览验收前不创建或发布英文正文，也不回退中文。

这里的“完成”指后台数据、详情接口、上传、发布、缓存和表单运营闭环。产品/方案详情、首页、关于我们、解决方案聚合页、页头页脚导航及联系页展示文案目前仍使用原 React 受控布局；对应 CMS 数据已迁入并校验，但必须通过保持原 DOM/CSS 的逐组件适配器接入，不能再以通用模板替换这些高度定制页面。原站本身标记“待补充”的产品介绍也原样保留，未虚构客户内容。因此不能将当前状态表述为“全站每一个可见字都已 100% CMS 化”。

## 接口与安全

- 内容读取只经 BFF 的只读 Token；Strapi Public Role 已关闭，未授权直连 `/api` 返回 403。
- 内容读 Token、表单写 Token、Webhook 密钥、招聘访问 Token 相互分离。
- BFF 提供产品分类、产品详情、行业方案、新闻、搜索、URL 解析、站点地图、联系表单、简历和健康检查接口。
- 中文不存在返回 404；英文未发布同样返回 404，不混入中文。
- 联系信息在日志和后台摘要中脱敏，原字段加密保存；接口有校验、限流和超时。
- 简历不进入公开媒体库；校验 PDF/DOC/DOCX 签名、MIME、扩展名和大小。
- 仅授权招聘 Token 可生成 5 分钟下载签名；仅 `clean` 文件可下载，并记录审计。
- 提供 ClamAV 扫描任务、180 天保存期限清理任务、PM2 定时任务配置。
- Strapi 内容创建、修改、删除后会向 BFF 发送带时间戳和 HMAC 的缓存失效通知；当前 PM2 保持单 BFF worker，避免进程内缓存和限流状态在多 worker 间不一致。
- 普通 `cms:seed` / `cms:seed:sync` 只补缺失数据，不覆盖后台人工修改；迁移重置必须显式运行危险命令 `cms:seed:force`。

## 日常运营

内容编辑入口为 `http://127.0.0.1:1337/admin`。本地管理员邮箱为 `admin@hongyun.local`，密码只保存在不入库的 `apps/cms/.env`。

更新前先保留草稿，预览确认后发布。产品多分类路径通过展示位和 URL 别名维护；不要复制产品正文。英文翻译到齐后，在对应中文条目中创建 `en` 本地化版本，完成整页预览后再发布。

常用命令：

```bash
pnpm cms:seed
pnpm cms:verify
pnpm cms:verify:live
pnpm check
pnpm --filter @hongyun/cms resume:scan
pnpm --filter @hongyun/cms retention:cleanup
```

`pnpm cms:seed:force` 会覆盖后台现有中文内容，只允许在确认重置迁移数据且已备份时使用。
