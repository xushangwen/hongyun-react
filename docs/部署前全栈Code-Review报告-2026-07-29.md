## 结论

工程链路和 CMS 数据已经达到可部署状态，但暂不建议直接对公网正式发布，当前为“有条件通过”：

1. 必须由业务/法务提供并确认隐私政策、版权声明和表单个人信息告知；当前页脚链接仍为 `#`。
2. 必须确认是否允许三个正式路由继续展示“待补充”内容。
3. 必须对 `pnpm audit --prod` 的 13 项上游依赖告警做上线例外确认，并保持 CMS 后台仅限白名单/VPN。
4. 正式域名、备案、ECS、安全组、MySQL、HTTPS、Mapbox Token、SMTP/线索通知方式仍需在真实阿里云环境完成。

满足以上条件后，可按根目录《部署指南》执行宝塔部署。

## 本轮已修复

### P0 阻断

- 旧部署文档仍按“腾讯云纯静态站”操作，无法启动 BFF、CMS、定时任务或备份。已重写为阿里云 ECS + 宝塔三层部署流程。
- PM2 直接启动 Nitro 构建产物时不会自动读取 `apps/api/.env`。已通过 Node `--env-file` 加载，并增加生产关键变量启动校验。
- 原 Nginx 只反代 `/admin`，Strapi 的 `/content-manager`、`/upload` 等后台接口会落入 React SPA。已改为独立 CMS 域名整站反代。
- Strapi 5 生产后台需要信任 HTTPS 反代头。已按 Koa proxy 模式配置，避免登录 Cookie 被识别为非安全连接。

### P1 主要问题

- 职位详情弹窗只提交文件和岗位，但后端强制要求姓名和电话，入口必然失败。已补齐姓名、电话、邮箱。
- 前端允许 PPT/JPG/PNG，后端只接受 PDF/DOC/DOCX。已统一文件类型和提示。
- 技术咨询提交了行业字段，但 contracts、BFF 和 CMS 模型未保存。已补齐全链路字段。
- 移动端职位弹窗被固定头部遮挡。已修正弹层层级。
- 首页轮播进度条使用可点击 `div`，键盘无法操作。已改为带 `aria-label` 和 `aria-current` 的按钮。

### P2 运维与安全

- Nginx 已增加表单限流、请求体限制、安全响应头、静态缓存，并封闭公网 webhook。
- 招聘下载接口和 CMS 后台示例默认只允许固定 IP/VPN。
- MySQL 备份增加 `--no-tablespaces`，校验工具兼容 Linux `sha256sum` 与 macOS `shasum`。
- React Router、`qs`、`@types/qs`、`mysql2` 已升级到当前可用补丁版本。
- `.env.production` 已纳入忽略规则，部署文档补齐前端生产环境变量。

## 仍需处理的发现

### [P1] 个人信息告知与法律页面缺失

- 位置：`src/components/Footer.jsx:100`、`src/components/Footer.jsx:102`
- 影响：技术咨询和简历表单收集姓名、电话、邮箱、公司及简历，但用户无法查看实际隐私政策；不应在未确认处理目的、保存期限、联系方式和权利路径前正式发布。
- 建议：由业务/法务提供最终文本，再实现真实 `/privacy` 和 `/legal` 页面，并在两个表单提交按钮前加入明确同意项。

### [P1] 正式页面仍展示占位内容

- `/products/solid-state-battery/ssb-multi-mixer`：产品介绍待补充
- `/products/new-energy/twin-screw-pulper`：参数内容待补充
- `/solutions/solid-state-battery/wet-electrode-system`：系统特点、设备介绍、参数、客户案例待补充
- 影响：削弱企业官网可信度，也可能导致销售线索获得不完整技术信息。
- 建议：业务确认正式文案/数据后录入 CMS；不能虚构技术参数。

### [P1] 生产依赖审计仍有上游告警

- `pnpm audit --prod`：13 项，含 3 high、9 moderate、1 low。
- 前端 React Router high 针对 RSC Action，而本站是纯 SPA，不使用 RSC。
- 多项 Vite、Hono 和路径告警限定开发服务器或 Windows，而生产目标为 Linux，且不运行开发服务器。
- 其余多来自 Strapi 5.51.0 的锁定间接依赖，当前无可安全单独升级路径。
- 建议：记录上线风险接受；CMS 后台保持 HTTPS + 白名单/VPN；不在生产运行 Vite dev；Strapi 发布兼容补丁后立即复测升级。

### [P2] Mapbox 包较大

- 生产 chunk：约 1,867.70 kB，gzip 约 520.79 kB。
- 已按 Contact 路由懒加载，不影响首页首包，但进入联系页仍有明显下载成本。
- 建议：后续将地图进一步拆到“联系方式”Tab 激活后再动态加载。

### [P2] SPA SEO 能力有限

- 标题、description、canonical 与 OG 标签由客户端 JavaScript 更新。
- 搜索引擎通常可执行 JavaScript，但部分社交分享和弱爬虫无法读取详情页动态元数据。
- 建议：正式 SEO 投放前为产品、方案和新闻详情增加预渲染或 SSR。

### [P2] 新线索没有主动通知

- 当前咨询和简历会可靠写入 CMS，但没有 SMTP、企业微信或钉钉提醒实现。
- 建议：上线前明确后台巡检责任人，或补充通知通道与失败重试。

### [P2] 单实例状态限制

- BFF 缓存和限流为进程内 Map，只能保持单实例。
- 当前 PM2 已固定一个 worker；扩容前必须迁移到 Redis 等共享存储。
